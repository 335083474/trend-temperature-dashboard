# 趋势温度观察台

在线访问：https://335083474.github.io/trend-temperature-dashboard/

五类资产的价格、温度与指标观察看板。包含417条周线、258条日线温度观测，以及4,798条独立本地行情快照。

支持价格折线/本地K线、温度色带、强度、均线、EMA单线及5/10/20/60组合、EMA斜率（每观测期百分比）、布林带、RSI、MACD、区间涨跌幅、历史波动率HV（非年化）、成交量、换档定位、五资产对照和当前区间CSV导出。

## 数据口径

- 周线2025-02-24至2026-09-28；日线各自起点不同，至2026-10-16。两个产品视图不拼接，周日期是产品周标签。
- 黄金三处日线价格OCR漏读已依据原图更正；A股2026-05-25强度主数字38/旁注30的不一致保留标记。
- 本地ETF/期货/聚合行情为独立对照代理，未认证等同产品指数。ETF原始不复权行情截至2026-09-16；A股聚合截至2026-09-08；AU0/SC0截至2026-10-16。
- 缺失标签和价格不补值。技术指标周期按有效日/周观测数计算；预热使用所选价格序列的前置历史。
- 这是公开历史快照，更新需要重新发布。本页不连接交易账户，不自动获取实时行情。

`site/publication.json` 记录发布版本、数据覆盖及文件SHA256。`site/` 通过GitHub Actions发布到GitHub Pages。源研究文件在本地维护，本仓库保存经验证的静态发布包。
